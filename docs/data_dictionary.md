# Diccionario de extracción

Una fila es un registro numérico publicado, no un sujeto ni observación independiente para regresión.

- record_id: identificador único.
- source_id: clave del registro de fuentes.
- entity: entidad que publica o reporta.
- metric: nombre operativo, sin asumir armonización.
- reference_year: año de referencia o etiqueta; no fecha de publicación.
- value: valor publicado.
- unit: percent, percent_per_year, tonnes o BRL.
- scope: universo y cobertura.
- locator: página, hoja o sección.
- interpretation_note: limitación que debe conservarse.

No agregar porcentajes entre fuentes. No interpretar propiedades del envase como reciclaje efectivo. No inferir causalidad.
